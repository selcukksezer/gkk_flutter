## 6. Mobile & Impeller TBDR Optimization Guide

### Why 1K & 2K Resolutions Are Mandatory for Mobile iOS / Android:
1. **VRAM Footprint & TBDR Tile Memory Budget**:
   - On mobile GPUs (Qualcomm Adreno, ARM Mali, Apple A/M series), fragment shading is performed in high-speed On-Chip Tile Memory (typically 512KB–1MB per tile).
   - Uncompressed 4K textures consume **64 MB per map** (256 MB for a 4-map PBR set). Loading multiple 4K sets easily triggers Mobile OS Out-Of-Memory (OOM) killer on 3GB/4GB Android devices.
   - In contrast, 1K textures consume only **4 MB** (uncompressed) or **~0.6–1.2 MB** when compressed with ASTC/ETC2 via KTX2. 2K textures consume **~2.5–4.8 MB** in ASTC. This ensures silky smooth 60 FPS without thermal throttling or garbage collection spikes.
2. **ARM Packed Textures (AO + Roughness + Metallic in 1 Texture)**:
   - Standard glTF PBR packing combines:
     - **R Channel**: Ambient Occlusion (AO)
     - **G Channel**: Roughness
     - **B Channel**: Metallic
   - Poly Haven provides pre-packed `_arm` textures (see tables above). Using ARM reduces mobile fragment shader texture samplers from **3 separate texture lookups to 1 single lookup**, slashing mobile memory bus bandwidth by 66%!
3. **DirectX vs OpenGL Normal Maps**:
   - Poly Haven provides both `nor_gl` (OpenGL: +Y Up) and `nor_dx` (DirectX: -Y Down).
   - **Flutter Impeller and Blender MCP use OpenGL (`nor_gl`)**. Always use `_nor_gl` files for Flutter and Blender assets to ensure inverted lighting artifacts do not occur.
4. **HDRIs in Mobile Rendering**:
   - 1K/2K `.hdr` or `.exr` files are optimal for mobile environment lighting. Poly Haven's 1K HDRIs average **1.5 MB**, offering instantaneous load times and zero render stalls.
